# Freedom Bot

Telegram-бот для Minecraft-сервера **FREEDOM** — двухфакторная защита игрового аккаунта и адресные уведомления вместо общего потока новостей.

Проект разрабатывается как учебный в рамках курса ООП.

---

## Концепция

Бот решает две задачи игрока.

**1. Защитить аккаунт.** Игрок привязывает свой игровой аккаунт к Telegram. Привязка даёт серверу доверенный канал связи с конкретным человеком — через него подтверждаются действия, требующие второго фактора помимо пароля.

**2. Не пропустить важное и не утонуть в неважном.** В общем Telegram-канале сервера всё идёт одним потоком: и критичные объявления, и анонсы ивентов, и розыгрыши. В итоге игрок либо отключает уведомления канала и пропускает действительно важное, либо получает всё подряд. Бот разбирает поток на категории и присылает каждому только то, на что он подписан.

### Что сможет пользователь

- Привязать игровой аккаунт к Telegram и отвязать его
- Включить и выключить двухфакторное подтверждение
- Подтверждать защищённые действия прямо в чате с ботом
- Подписываться и отписываться от категорий уведомлений по отдельности:
    - критичные новости сервера
    - ивенты
    - розыгрыши
- Посмотреть состояние своей привязки и активных подписок

## Как задумано подтверждение

```
Игрок выполняет защищённое действие
        ↓
Сервер видит, что у аккаунта включено подтверждение
        ↓
Бот присылает в Telegram запрос: "Это вы?"
        ↓
Игрок нажимает "Да"  →  действие выполняется
Игрок нажимает "Нет" →  действие отклоняется
```

Привязка аккаунта — фундамент, на который этот механизм опирается. Конкретный набор защищаемых действий определяется отдельно: на сервере уже есть аутентификация по паролю, поэтому второй фактор имеет смысл там, где цена ошибки выше обычного входа.

## Команды

| Команда | Что делает |
|---|---|
| `/about` | Назначение бота |
| `/author` | Информация об авторах |
| `/help` | Список всех доступных команд |
| `/help <command>` | Справка по конкретной команде |

Список пополняется по мере разработки. Справка формируется автоматически из зарегистрированных команд — добавление новой команды не требует правки `/help`.

## Сборка и запуск

```bash
git clone https://github.com/FreedomMinecraft/freedom-bot.git
cd freedom-bot
```

Скопировать `config.properties.example` в `config.properties` и вписать туда токен бота, полученный у [@BotFather](https://t.me/BotFather):

```properties
bot.token=ВАШ_ТОКЕН
bot.username=ИМЯ_БОТА
```

Файл `config.properties` добавлен в `.gitignore` и в репозиторий не попадает — токен остаётся только на вашей машине.

Собрать и запустить:

```bash
mvn clean package
java -jar target/freedom-bot.jar
```

## Разработка

Ветка `main` защищена, разработка ведётся в отдельных ветках.

1. Ветка от `main`: `feature/...`, `fix/...`, `docs/...`
2. Атомарные коммиты — один коммит решает одну задачу
3. Push ветки
4. Pull Request с ревью второго участника
5. Merge в `main`, ветка удаляется
