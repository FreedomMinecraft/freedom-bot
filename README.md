# Freedom Bot

Telegram-бот для Minecraft-сервера **FREEDOM** — двухфакторная защита игрового аккаунта, рассылка самых важных новостей и путеводитель по серверу.

Проект разрабатывается как учебный в рамках курса ООП.

---

## Концепция

Бот решает три задачи игрока.

**1. Защитить аккаунт.** Игрок привязывает свой игровой аккаунт к Telegram. Привязка даёт серверу доверенный канал связи с конкретным человеком — через него подтверждаются действия, требующие второго фактора помимо пароля.

**2. Не пропустить важное и не утонуть в неважном.** В общем Telegram-канале сервера всё идёт одним потоком: и критичные объявления, и анонсы ивентов, и розыгрыши. В итоге игрок либо отключает уведомления канала и пропускает действительно важное, либо получает всё подряд. Бот присылает самые важные новости сервера, а остальные уведомления игрок включает сам по категориям.

**3. Быстро разобраться в сервере.** Бот работает как путеводитель: рассказывает о расах и кланах, показывает, кто входит в админ-состав, и подсказывает, какие чаты есть у сервера и для чего каждый из них.

### Что сможет пользователь

- Привязать игровой аккаунт к Telegram и отвязать его
- Включить и выключить двухфакторное подтверждение
- Подтверждать защищённые действия прямо в чате с ботом
- Получать самые важные новости сервера
- Подписываться и отписываться от дополнительных оповещений:
    - оповещения об ивентах
    - оповещения о розыгрышах
- Посмотреть список рас и сколько игроков сейчас в каждой из них
- Посмотреть список кланов с подробным описанием
- Узнать админ-состав сервера, ивенторов и медиа-состав со ссылками на их каналы
- Получить информацию о чатах сервера
- Посмотреть состояние своей привязки и активных подписок

## Путеводитель

### Расы

На сервере 17 рас. Подробно о каждой — способности, сильные и слабые стороны — в [вики сервера](https://freedom-minecraft.gitbook.io/wiki/start-game/races):

Человек, Авиан, Коточеловек, Эльф, Арахнид, Вампир, Ящер, Ведьма, Гном, Эндерианец, Элитрианец, Заклинатель, Пчела, Гигант, Зиморождённый, Мерлин, Огнерождённый.

Бот покажет все расы и текущее количество игроков в каждой. Количество считается по данным сервера на момент запроса, поэтому в README не фиксируется.

### Кланы

По каждому клану бот выдаёт подробную карточку:

- название и глава клана
- описание и направленность
- количество участников и кто в нём состоит (глава и заместители)

Если глава клана подтвердил учётную запись через бота, он сам настраивает, что именно будет написано о клане: описание редактирует он, а не плагин подставляет его из базы. Из базы данных кланов подтягиваются только название, количество игроков и представители клана — глава и заместители.

Список кланов бот будет получать с сервера. Пример того, как выглядят данные (кланы вымышленные):

| Клан | Глава | Описание |
|---|---|---|
| Северный Альянс | Leader_North | Мирный клан строителей: общий город в заснеженной долине |
| Пепельные Клинки | Leader_Ash | PvP-клан, участвует в клановых войнах и турнирах |
| Торговая Гильдия | Leader_Gold | Экономика сервера: рынок, заказы ресурсов, аукционы |

### Админ-состав

Бот показывает администрацию сервера командой `/admins`: ник в игре и должность — администратор, старший модератор, модератор, хелпер. Отдельно — ивенторы (`/eventors`) и медиа-состав со ссылками на их каналы (`/media`).

Личные контакты администрации бот не показывает. С любым вопросом игрок пишет в поддержку, и `/admins` подсказывает, куда именно: бот поддержки, сообщения Telegram-канала или тикеты в Discord.

Состав хранится в файле `bot/src/main/resources/server-info.json`. Когда в администрации что-то меняется, правится только этот файл — код не трогаем.

## Как устроена привязка аккаунта

Бот реализован как чат-бот: привязка проходит в виде диалога, а не одной командой. Бот задаёт вопросы по шагам и помнит, на каком шаге сейчас находится пользователь. Взаимодействие идёт через меню: основной способ — кнопки, команды остаются как альтернатива.

### Пример диалога

```
Игрок: жмет на кнопку «Привязать аккаунт»
Бот:   Какой у тебя ник на сервере?
Игрок: Steve123
Бот:   Я отправил код в игровой чат. Введи его сюда.
Игрок: 4821
Бот:   Готово, аккаунт Steve123 привязан. Включить подтверждение входа? (да/нет)
Игрок: да
Бот:   Двухфакторное подтверждение включено.
```

### Шаги

```
Пользователь нажимает кнопку «Привязать аккаунт»
        ↓
Бот запрашивает ник на сервере
        ↓
Сервер отправляет одноразовый код в игровой чат этого игрока
        ↓
Пользователь вводит код в Telegram
        ↓
Код верный   →  аккаунт привязан, бот предлагает включить подтверждение
Код неверный →  бот просит ввести код ещё раз
```

Код приходит только в игру, поэтому привязать аккаунт может лишь тот, кто действительно в него зашёл. Чужой ник указать можно, но без кода из игры привязка не завершится.

### Крайние случаи

**Код не введён.** Код действует 2 минуты, после чего сгорает, а диалог возвращается в состояние `IDLE`. На игрока хранится только один активный код: новый запрос затирает предыдущий. Попыток ввода — 3, дальше код сгорает досрочно, иначе четырёхзначный код подбирается перебором. Запрашивать код можно не чаще 3 раз за 10 минут.

```
Бот: Код действует 2 минуты.
     ...
Бот: Время вышло, код больше не действует.
     [Отправить новый код]  [Отмена]
```

**Введён неверный ник.** Формат ника (3–16 символов: буквы, цифры, подчёркивание) бот проверяет сам, существование игрока — запросом через плагин на сервер.

```
Игрок: Stve123
Бот:   Игрока с таким ником нет на сервере. Проверь написание и пришли ещё раз.
       [Отмена]
```

Если сервер не ответил, бот так и пишет: «сервер сейчас недоступен, попробуй позже», и не сбрасывает диалог.

**Ник уже привязан.** Telegram того, кто привязал аккаунт, бот не показывает. Снять чужую привязку можно только из игры — командой `/tglink reset`, то есть спор снова решает доступ к игровому аккаунту.

```
Бот: Этот аккаунт уже привязан к другому Telegram.
     Если это твой аккаунт, отвяжи его командой /tglink reset в игре или напиши администрации.
     [Написать админам]  [Отмена]
```

**Отвязка аккаунта.** Нужна, потому что на сервере игрокам иногда позволяют менять ники.

```
Игрок: [кнопка «Отвязать аккаунт»]
Бот:   Отвязать Steve123? Двухфакторка и уведомления отключатся.
       [Да, отвязать]  [Отмена]
Игрок: [Да, отвязать]
Бот:   Аккаунт отвязан.
```

Если двухфакторное подтверждение включено, отвязка тоже подтверждается кодом из игры - иначе тот, кто получил доступ к Telegram, просто снимет защиту.

Саму смену ника перепривязывать не нужно: привязка хранится по UUID игрока, поэтому при входе плагин видит прежний UUID с новым ником и просто обновляет ник в базе.

### Состояния диалога

Для каждого пользователя бот хранит текущее состояние, по нему понятно, как трактовать следующее сообщение:

| Состояние | Чего ждёт бот |
|---|---|
| `IDLE` | Обычный режим, диалог не начат |
| `WAITING_NICKNAME` | Ник игрока на сервере |
| `WAITING_CODE` | Код подтверждения из игрового чата |
| `WAITING_2FA_CHOICE` | Ответ «да» или «нет» на включение подтверждения |
| `WAITING_UNLINK_CONFIRM` | Подтверждение отвязки аккаунта |

У активного кода дополнительно хранятся время истечения и число оставшихся попыток.

## Как задумано подтверждение

```
Игрок выполняет защищённое действие
        ↓
Сервер видит, что у аккаунта включено подтверждение
        ↓
Бот присылает в Telegram запрос: "Это вы?"
        ↓
Игрок нажимает "Да"  →  действие выполняется
Игрок нажимает "Нет" →  действие отклоняется
```

Привязка аккаунта - фундамент, на который этот механизм опирается. Конкретный набор защищаемых действий определяется отдельно: на сервере уже есть аутентификация по паролю, поэтому второй фактор имеет смысл там, где цена ошибки выше обычного входа.

## Сборка и запуск

```bash
git clone https://github.com/FreedomMinecraft/freedom-bot.git
cd freedom-bot
```

Скопировать `config.properties.example` в `config.properties` и вписать туда токен бота, полученный у BotFather (https://t.me/BotFather):

```properties
bot.token=ВАШ_ТОКЕН
bot.username=ИМЯ_БОТА
```

Файл `config.properties` добавлен в `.gitignore` и в репозиторий не попадает — токен остаётся только на вашей машине.

Собрать и запустить:

```bash
mvn clean package
java -jar bot/target/freedom-bot.jar
```

## Структура проекта

Многомодульный Maven-проект: бот и плагин живут в одном репозитории, общий код вынесен в отдельный модуль.

```
freedom-bot/
├── pom.xml          # родительский: версия Java, версии библиотек, список модулей
├── common/          # общий код бота и плагина (форматы данных, категории уведомлений)
├── bot/             # Telegram-бот
├── plugin/          # плагин для сервера Paper/Purpur 1.21.10 (появится позже)
└── .github/         # CI (сборка и тесты на каждый PR) и шаблон Pull Request
```

Код лежит в пакетах `ru.freedomminecraft.<модуль>`.

## Разработка

Ветка `main` защищена, разработка ведётся в отдельных ветках.

1. Ветка от `main`: `feature/...`, `fix/...`, `docs/...`
2. Атомарные коммиты — один коммит решает одну задачу
3. Push ветки
4. Pull Request с ревью второго участника
5. Merge в `main`, ветка удаляется
